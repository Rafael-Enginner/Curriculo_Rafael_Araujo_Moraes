# Currículo online — Rafael Araújo Moraes

Estudante de Engenharia de Software, com experiência em rotinas administrativas e financeiras.

**Site:** https://rafael-enginner.github.io/Curriculo_Rafael_Araujo_Moraes/

Links por perfil de vaga: `?perfil=administrativo`, `?perfil=financeiro` ou `?perfil=processos`.

## Estrutura

| Caminho | Função |
|---|---|
| `index.html` | Conteúdo, metatags de compartilhamento e dados estruturados |
| `css/style.css` | Estilos: tema claro/escuro, responsivo, impressão |
| `js/script.js` | Perfil de vaga, filtro de competências, botões de contato |
| `assets/` | Currículo para download (PDF e Word) |
| `img/og-image.png` | Imagem de prévia do link |
| `404.html`, `robots.txt`, `sitemap.xml`, `favicon.svg` | Páginas e arquivos de suporte |

HTML, CSS e JavaScript puros, sem frameworks, publicados com GitHub Pages.

## Como atualizar

Edite o arquivo no GitHub (ícone de lápis), confirme na branch `main` com uma mensagem descritiva e aguarde de 1 a 2 minutos.

## Se o nome de usuário ou do repositório mudar

Troque o endereço do site em: `index.html` (canonical, og:url, og:image, JSON-LD), `404.html`, `robots.txt`, `sitemap.xml` e neste README.
